Step 2: Project Description

Paste this as your project description:

NeuroSys is an enterprise-grade AI-powered predictive system monitoring platform designed for schools, colleges, offices, and organizations.

The platform consists of a lightweight Java Monitoring Agent installed on every computer and a centralized Spring Boot backend with a React dashboard.

The Monitoring Agent continuously collects system metrics including CPU usage, memory usage, disk usage, network statistics, running processes, operating system information, uptime, and temperature (when available). Every few seconds it securely sends these metrics to the backend.

The backend stores historical metrics, generates alerts, calculates health scores, predicts future resource usage using machine learning, and provides optimization recommendations.

Administrators can monitor all computers from a single dashboard, receive real-time updates using WebSockets, analyze logs, and use an AI assistant to understand system issues.

The project should follow enterprise software architecture with clean code, modular design, security best practices, scalability, and production-ready standards.
